ffmpeg
================================================================================

This project uses ffmpeg as an external program for encoding, mixing and
concatenation. It is invoked as a separate process; no ffmpeg source code is
included in, is linked into, or is statically combined with this repository,
and this repository does not distribute any ffmpeg binary.

Project:  https://ffmpeg.org/
Legal:    https://ffmpeg.org/legal.html
Sources:  https://ffmpeg.org/download.html
